# Emirates Real Estate

## Overview

Emirates Real Estate is a web application designed to facilitate property listings, management, and transactions within the real estate industry. Users can browse properties, list new ones, and manage property details efficiently.

## Features

- **Property Listings**: Browse and search for available properties.
- **Add & Manage Listings**: Property owners can list and update property details.
- **Filtering & Sorting**: Easily find properties based on location, price, and type.
- **Responsive UI**: Optimized for both desktop and mobile users.

## Technologies Used

- **Frontend**:
  - React.js
  - Material-UI
- **Backend**:
  - Radpid Api Bayut Api


## Installation

1. **Clone the Repository**:

   ```bash
   git clone https://github.com/your-username/emirates_realState.git
   cd emirates_realState
   ```

2. **Install Dependencies**:

     npm install
    
4. **Start the Application**:

     ```bash
     npm start
     ```
